# Corrections and versions

Version 0.1.0 is the first edition. Zenodo published it on November 28, 2026 (UTC). The deposited archive matched the verified GitHub tag. [Version DOI](https://doi.org/10.5281/zenodo.24615122) · [Admission record](ADMISSION.md)

Please report corrections through the repository's issue tracker. Identify the version, the affected claim and a source or reproducible calculation. An earlier construction at any of the four orders warrants a dated priority correction. An error in the construction or certificate warrants a correction or withdrawal that names the affected orders. A later edition will identify the version it supersedes. Archived editions retain their original contents. [Issue tracker](https://github.com/jeff-kline/hadamard-order-15896/issues)
